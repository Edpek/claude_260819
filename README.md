# myclaude

Small, self-contained front-end prototypes. Each folder is a single-page app you can open directly with no build step.

## Projects

- [`creative-toy/`](creative-toy/index.html) — 파티클 플레이그라운드: an interactive canvas particle playground (trail, burst, and orbit modes) driven by mouse or touch.
- [`game/`](game/index.html) — 네온 스네이크: a neon-styled Snake game with keyboard, on-screen d-pad, and swipe controls, plus a local high-score record.
- [`productivity-tool/`](productivity-tool/index.html) — 포커스 타이머: a Pomodoro-style focus timer with work/short-break/long-break modes and a simple to-do list, both persisted to `localStorage`.

## Running locally

No dependencies or build tools are required. Open any `index.html` file directly in a browser, for example:

```bash
start creative-toy/index.html
```
